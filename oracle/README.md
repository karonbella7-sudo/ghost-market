## 交互

龟壳竖直从画面下方进入中央。按住龟壳移动鼠标或手指摇动，松开投掷。键盘聚焦龟壳后按住空格／Enter，松开投掷。三枚铜钱从龟壳上端开口抛出，向中央落下并放大；龟壳同时下沉离场。钱币位置与角度小范围随机，动画期间禁止重复投掷。点击 CAST AGAIN 重复。刷新会重置休市记录。

画面仅显示英文动作引导、英文开市／休市宣布、吉／平及再次投掷按钮。素材自身的书法笔画保留。吉／平字体优先古典明朝体，再回退到系统楷体；没有捆绑第三方字体文件。支持减少动态效果设置。

## 规则

字面为正、纹面为反。两正或三正为吉，100%开市；零正或一正为平，100%休市。普通投掷三枚独立随机。连续两次休市后，下回随机选择至少两正的组合，先决定钱面再计算结果，始终一致。

oracle-audio.js 使用 Web Audio 实时合成音效，无外部音频依赖。首次按住龟壳或键盘操作后开启声音：移动时触发短促铜钱碰撞；投掷后在三枚钱的首次触地与轻微反弹时触发更明亮的金属声；结果揭晓时触发一次低频寺钟及约七秒余音。摇动声随移动幅度变化，静止按住不会持续碰撞。键盘摇动有定时轻响。取消操作停止摇动声，切换到后台停止声音。吉与平使用同一钟声。声音总音量在 oracle-audio.js 的 master.gain.value 中调整（默认 0.48）。

音效修订：松手后约 25 毫秒开始出壳碰撞，三枚钱依次发出短促轻碰声；触地时加入宽频接触瞬态、低频撞击和短暂金属余响，后续有衰减的弹跳碰撞，减少原先偏铃铛的长响。平保留原 118 Hz 寺钟基音；吉改为 177 Hz（约高一个纯五度），余音结构相同。此修订替代上段关于吉平同一钟声的描述。

音色为合成模拟，并非寺庙或钱币实录。已检查语法及模拟音频触发、出壳和触地时间同步、两种结果音高；受本地浏览器工具限制，未完成实际听觉验收。若没有声音，请确认浏览器或系统未静音，并先在画面里按住龟壳。
